# Breakthrough thesis

## Working name

**RankLock: Width-Free Conditional Disclosure for Algebraic Programs**

Alternative title if the theorem is achieved:

> **Near-Native Fully Succinct Garbling for Large-Field Arithmetic**

## One-sentence target

Construct the first projective, publicly evaluable, malicious-generator-secure conditional
disclosure scheme for large-prime-field arithmetic programs whose persistent material and
expensive cryptographic evaluation depend on the program's unique low-rank templates and depth,
not on its scalar gate count.

## Why this would matter

Mosaic makes cut-and-choose usable on Bitcoin by removing the number of copies from the on-chain
input-label footprint, but it still creates, transfers, stores, and evaluates enormous off-chain
garbled circuits. Existing succinct garbling reduces material but pays expensive HSS/group work per
gate. Existing arithmetic and one-hot garbling exploit structure but still scale with the number of
arithmetic gates. Argo and BABE are dramatically smaller but specialized around elliptic-curve and
Groth16 structure.

The breakthrough is therefore not another 2× gate optimization. It is to make the cryptographic
cost look like:

```text
native verifier execution
+ a few folded/vector cryptographic checks per layer/template
+ a small projective input adapter
```

rather than:

```text
one authenticated ciphertext/MAC/HSS operation per scalar multiplication
× every cut-and-choose copy
```

## The exact novelty package

A publishable result must contain all four contributions:

1. **Rank-folded authentication.** A method to authenticate an entire native arithmetic trace by
   folding all bilinear residuals after a binding transcript commitment, with expensive work
   proportional to layers/templates rather than residual count.
2. **Distributed projective CDS.** A noninteractive conditional-release construction generated by
   multiple parties, secure when all but one are corrupt, with no online authority after activation.
3. **Template-amortized setup soundness.** One proof/certificate per unique low-rank template plus a
   batched binding to every instance, replacing 181-copy cut-and-choose.
4. **A certified verifier compiler.** Automatic extraction and exact certification of low-rank
   modules from the production verifier, followed by a real Strata/Bitcoin execution.

Dropping any one of these makes the result substantially less important:

- no distributed CDS → honest-signer architecture, not a Mosaic replacement;
- no template amortization → merely a smaller arithmetic garbling;
- no near-native evaluation → another succinct-but-slow HSS construction;
- no real compiler/application → a theoretical primitive with unclear impact.

## Current evidence

The v0.10 compiler already derives and certifies:

- BN254 `Fq12` multiplication at rank 54;
- BN254 `Fq12` squaring at rank 48;
- exact flat/tower equivalence through public linear maps;
- a conservative 645,221-rank-term schedule for the retained real SP1 verifier trace;
- a 20-round RankFold multiplication argument with an 83-field-element transcript;
- an executable proof that unbound PCS openings make the argument forgeable.

The missing result has narrowed to two cryptographic components: a binding succinct opening
scheme and an offline conditional-disclosure layer that is asymptotically or concretely better
than generic aHMAC/witness-encryption/garbled-verifier composition.
